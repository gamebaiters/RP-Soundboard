GameBaiters Soundboard 1.0.118
==============================

Bugfixes
--------
* Windows: pitch / speed sliders no longer break audio playback when
  moved off the center value. The Windows static FFmpeg build was
  missing the `atempo` and `asetrate` filters, so as soon as the
  filter graph included one of them (any non-zero pitch or speed)
  `avfilter_graph_parse_ptr` returned -22 (EINVAL) and playback stopped
  until the slider was returned to 0. The static build now enables
  `atempo,asetrate` alongside the existing audio filters. Reverb was
  not affected because reverb is processed in-plugin (Freeverb), not
  via the FFmpeg filter graph.

* Windows / Linux installs are now clean. Previous releases shipped a
  single multi-platform .ts3_plugin that contained the macOS
  `libavcodec.62.dylib`, `libavfilter.11.dylib`, `libssl.3.dylib`, etc.
  alongside the Windows DLL and Linux .so. TeamSpeak's installer
  unconditionally extracts every file in the archive, so Windows users
  ended up with ~20 macOS dylibs in their plugin folder doing nothing.
  The release now ships three platform-specific .ts3_plugin files:
    - rp_soundboard_fx_<ver>_win64.ts3_plugin
    - rp_soundboard_fx_<ver>_linux_amd64.ts3_plugin
    - rp_soundboard_fx_<ver>_macos_x86_64.ts3_plugin
  plus the existing Install_Soundboard_macOS.zip wrapper for macOS
  users. Each archive contains only the binary for that platform.
  Auto-update on Windows now points at the win64-only file.

Carried over from 1.0.117
-------------------------
* macOS: best-effort dual API for `abuffersink` format constraints
  (FFmpeg 8 renamed `sample_fmts` BINARY -> `sample_formats` STRING).
  Cross-compatible with FFmpeg 6.x (Windows static), 7.x, and 8.x.
* macOS: plugin links against the bare Qt5 dylibs that TS3.app ships
  inside Contents/Frameworks (no QtWidgets.framework bundle).
* macOS: xattr -cr on the entire plugin folder after install.
* macOS: recursive dependency bundler with @loader_path rewrites for
  every Homebrew transitive dep.
* macOS: re-codesign each Mach-O on the user's machine after copy.

Reminder for users on Apple Silicon
-----------------------------------
* TeamSpeak 3 on macOS is x86_64-only regardless of Mac hardware -
  it runs through Rosetta 2 on Apple Silicon. The plugin therefore
  ships as x86_64.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots)

Installation
------------

* Windows: download rp_soundboard_fx_<version>_win64.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, RIGHT-CLICK
  Install Soundboard.app -> Open the first time so macOS Gatekeeper
  accepts the ad-hoc signature.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts in the release assets keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
