GameBaiters Soundboard 1.0.117
==============================

Critical macOS file-playback fix (real one this time)
-----------------------------------------------------
* 1.0.116 attempted to fix macOS playback by terminating the
  abuffersink format arrays with AV_SAMPLE_FMT_NONE / -1
  sentinels - this was the right fix for FFmpeg 7, but the
  Homebrew runner is on FFmpeg 8.1, where the abuffersink option
  `sample_fmts` was REPLACED by `sample_formats` (a STRING type
  taking '|'-separated values, not BINARY anymore). Trying to
  write a binary array into a string option returned EINVAL
  (-22) so the filter graph never built and every play attempt
  silently failed.

  Fix: best-effort dual API for the abuffersink format
  constraints - try the FFmpeg 8 STRING name first, fall back to
  the FFmpeg 6/7 BINARY name. Never bail on failure, because the
  `aformat` filter at the end of our filter chain already forces
  s16 / 48000 Hz / stereo before the sink, so the sink doesn't
  need explicit constraints to receive the right format.
  Cross-compatible with FFmpeg 6.x (Windows static build),
  FFmpeg 7.x, and FFmpeg 8.x.

Carried over from 1.0.116 / 1.0.115
-----------------------------------
* Plugin links against the bare Qt5 dylibs that TS3.app ships
  inside Contents/Frameworks (no QtWidgets.framework bundle on
  macOS - TS3 ships flat libQt5*.dylib).
* xattr -cr on the entire plugin folder after install (clears
  quarantine on every transitive bundled dep).
* Recursive dependency bundler with @loader_path rewrites for
  every Homebrew transitive dep (libssl, libvpx, libx264, ...).
* Strip ad-hoc signature before install_name_tool changes; final
  3-pass sweep catches any silent rewrite failures.
* Re-codesign each Mach-O on the user's machine after copy.

Reminder for users on Apple Silicon
-----------------------------------
* TeamSpeak 3 on macOS is x86_64-only regardless of Mac hardware -
  it runs through Rosetta 2 on Apple Silicon. The plugin therefore
  ships as x86_64.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots)

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, RIGHT-CLICK
  Install Soundboard.app -> Open the first time so macOS Gatekeeper
  accepts the ad-hoc signature.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts in the release assets keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
