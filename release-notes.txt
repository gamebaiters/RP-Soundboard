GameBaiters Soundboard 1.0.111
==============================

Critical fix
------------
* Windows plugin failed to load on 1.0.110. The CI built against
  FFmpeg 8.x master and did not bundle the FFmpeg shared DLLs into
  the .ts3_plugin, so on the user side TeamSpeak found the plugin
  binary but could not resolve any av_* symbol and silently dropped
  the plugin. Fixed by:
  - Pinning the CI Windows build to FFmpeg n6.1.1 (avcodec-60,
    avformat-60, avutil-58, swresample-4, avfilter-9) so the SO
    names match the DllMain delay-load pragmas in plugin.cpp.
  - Bundling avcodec-60.dll / avformat-60.dll / avutil-58.dll /
    swresample-4.dll / avfilter-9.dll / swscale-7.dll inside
    plugins/rp_soundboard/ so DllMain's LoadLibraryExW preload
    succeeds.

UI fixes (carried over from 1.0.110)
------------------------------------
* Checkbox indicators no longer render the playback arrow icon when
  toggled - now show a clean filled square in the accent color.
* Per-slot FX slider labels and value readouts bumped from 7-8 pt
  bold to 9-10 pt regular so they are legible at every screen scale.
* Per-slot Reset button label expanded from "Rst" to "Reset"; width
  widened so the text never gets clipped.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection (local hard-limiter)
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots playing concurrently)
* Update channel served from this gamebaiters branch on GitHub
* Auto-updater that closes TeamSpeak, removes the previous binary,
  preserves your rp_soundboard.ini config, then runs the installer

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click to install via TeamSpeak's bundled installer.
* macOS: download Install_Soundboard_macOS.zip, unzip and double-click
  Install Soundboard.app. Right-click -> Open the first time if macOS
  Gatekeeper blocks it.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts (in the release assets) keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
