GameBaiters Soundboard 1.0.115
==============================

Critical macOS fix
------------------
* Plugin failed to load with the error
    Library not loaded: @rpath/QtWidgets.framework/Versions/5/QtWidgets
  even after the quarantine xattr fix in 1.0.114. Root cause: TeamSpeak 3
  on macOS does NOT ship Qt as framework bundles - it ships flat,
  bare-named dylibs (libQt5Core.dylib, libQt5Widgets.dylib, ...)
  inside Contents/Frameworks/. Linking the plugin against Homebrew's
  framework-form Qt baked '@rpath/QtWidgets.framework/Versions/5/
  QtWidgets' into the plugin's load commands; dyld then searched for
  that exact path inside TS3.app and failed.

  Fix: CI now passes -DTS3_MAC_QT_LIB_DIR=/Applications/TeamSpeak 3
  Client.app/Contents/Frameworks to CMake, which redirects Qt5::Core /
  Widgets / Gui / Network to the bare dylibs TS3 ships. The
  post-link rewriter also normalises any remaining Qt ref to the
  '@rpath/libQt5XYZ.dylib' bare form. The runner now has a sanity
  check that fails the build early if TS3.app Qt dylibs aren't
  present at the expected path.

Carried over
------------
* xattr -cr on the entire plugin folder after install (clears
  quarantine on every transitive bundled dep) - fixes "failed to
  open plugin" caused by Gatekeeper blocking quarantined dylibs.
* Recursive dependency bundler with @loader_path rewrites for
  every Homebrew transitive dep (libssl, libvpx, libx264, ...).
* Strip ad-hoc signature before install_name_tool changes; final
  3-pass sweep catches any silent rewrite failures.
* Re-codesign each Mach-O on the user's machine after copy.

Reminder for users on Apple Silicon
-----------------------------------
* TeamSpeak 3 on macOS is x86_64-only regardless of Mac hardware -
  it runs through Rosetta 2 on Apple Silicon. The plugin therefore
  ships as x86_64.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots)

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, RIGHT-CLICK
  Install Soundboard.app -> Open the first time so macOS Gatekeeper
  accepts the ad-hoc signature.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts in the release assets keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
