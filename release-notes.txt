GameBaiters Soundboard v2.2.8
=============================

Reverse-playback release on top of v2.2.7. New: per-cell and per-channel
REVERSE button that plays a sound backwards in real time with pitch /
speed / reverb / loop / crop markers all behaving exactly as in forward
playback. The EQ visualiser was rewritten from scratch (FFT-driven
per-band LED column, preset dropdown). The Leia spatial engine now
ships 13 room presets with dramatically different character (Schroeder
diffuse tail + per-preset absorption / damping signatures). Cluster of
GUI bug fixes around stale visuals after audio stops.

---------------------------------------------------------------------
REVERSE PLAYBACK
---------------------------------------------------------------------
* New: REVERSE button on the waveform player (next to LOOP) plays the
  current sound backwards. Cursor tracks from the right edge toward
  the left, crop start / end markers swap roles, the time label still
  reads forward-time (so "12 s / 30 s" means 12 seconds since playback
  start). Toggling reverse mid-playback keeps the audible position
  exactly where it was (no skip forward / backward).
* New: per-cell "Play in reverse" flag in the cell editor that makes
  a specific sound always trigger in reverse without touching the
  channel-wide button.
* Reverse + pitch / speed / reverb is now seamless. Previously the
  filter graph and reverse pre-decode were built BEFORE the active
  pitch / speed / reverb factors had been applied, so the first ~250
  ms of every reverse-mode play would briefly leak unprocessed audio
  before the debounced rebuild caught up. The factors are now staged
  into the new InputFile BEFORE open(), so the pre-decoded reverse
  buffer is built directly at the user's current pitch / speed and
  the filter graph adopts the reverb mix from the first sample.
* Live slider drags during reverse playback no longer cause cursor
  jumps. The buffered-time math used the Sampler-global speedFactor
  against samples that had been produced at the per-slot factor; with
  reverse engaged the cursor saw the discrepancy as a jump backward.
  Position cache now uses the per-slot speed factor exactly like
  forward playback, with monotonic-direction-aware guards.
* Loop + reverse + crop now restarts the input from cropEnd (or full
  length when no crop is set) instead of cropStart, so a looping
  reverse-mode sound starts each iteration from the right marker
  and walks back to the left, matching what the cursor shows.

---------------------------------------------------------------------
EQ VISUALISER REWRITE
---------------------------------------------------------------------
* New: custom EqBandWidget replaces the stock QSlider for every band.
  Vertical 5-stop LED gradient (deep blue at the bottom, hot red at
  the top), level overlay reacts in real time to per-band energy.
  Band energies are driven by a dedicated FFT analysis pass in EqRack
  (Hann-windowed 2048-pt, 2/3-octave bin aggregation) so each band
  only lights up on its OWN frequency content - the bug where every
  band moved in sync with broadband level is gone.
* New: EQ preset dropdown. Built-in presets (Flat / Low cut / High
  cut / Smile / Voice) are always available and cannot be deleted.
  User presets save / delete from the same dropdown via persistent
  storage (PresetManager, sandbox_eq_presets section).
* Slider drag now stays smooth - earlier custom mousePressEvent did
  not engage QStyle's drag-tracking machinery, so drags missed clicks
  near the thumb. Wheel = +/- 1 dB (Shift = +/- 3 dB), middle-click
  resets to 0 dB, right-click opens a context menu.
* The "Restore session" path now re-feeds analysis into EqRack so
  channels restored at TS3 startup don't sit with frozen LED bars
  until the next playback.

---------------------------------------------------------------------
LEIA HRTF: 13 ROOM PRESETS
---------------------------------------------------------------------
* New: ShoeboxRoom now exposes 13 named presets (Tight booth /
  Bedroom / Bathroom / Hall / Cathedral / Underwater / Cave /
  Hangar / Stage / Studio / Vintage / Forest / Outdoor) with
  full character signatures: per-band absorption[6], lateFeedback,
  lateDamp, lateMix, tapLpHz, erDelayScale. Switching presets
  produces audibly distinct rooms - bathroom is bright and short,
  cathedral is wash + long tail, underwater is heavily LP-filtered.
* The diffuse tail is now a Schroeder reverb (4 parallel damped
  combs + 2 series allpasses) fed by the DRY signal so a real
  audible wash develops on top of the early-reflection pattern,
  rather than the earlier "feed ER taps into the tail" design
  which produced an almost inaudible tail at long decay times.
* Per-tap one-pole low-pass cutoff is derived from the preset's
  absorption[6] + per-preset bias, so high-frequency damping
  matches the room character at every reflection bounce.
* Per-tap gain ramping (prevGainL / prevGainR -> targetGainL /
  targetGainR over the block) kills the rotation zipper that
  used to ride the reflections when a moving source crossed
  the per-tap pan-law boundaries.

---------------------------------------------------------------------
GUI / VISUAL BUGFIXES
---------------------------------------------------------------------
* Fixed: EQ LED bars and channel meter peak-hold froze on the last
  frame the instant the user stopped the last playing sound. The
  meter timer early-returned on !sampler->anyPlaying(), so the
  (0, 0) drain frames that fade decays back to floor were never
  pushed. Timer now keeps pumping for ~3 s after anyPlaying() goes
  false (75 ticks @ 40 ms), enough for every decay (EqBandWidget
  release coefficient 0.10, peak-hold multiplicative decay) to
  reach >99% settled. Counter resets to 75 every tick while audio
  is playing, so a new sound restarts the drain window from
  scratch. EqBandWidget setLevel now change-detects against the
  smoothed display value and snaps to floor below 0.002, so the
  silent-channel drain ticks settle to a clean stop with zero
  paint cost once everything is at rest.
* Fixed: TS3 crash on close when the log-viewer dialog had been
  opened during the session. logViewerDialog was new'd lazily on
  first open but never delete'd in sb_kill, so TS3's plugin
  unload sequence ran into a Qt widget whose parent was already
  destroyed. The dialog is now explicitly deleted + nulled at
  the top of sb_kill alongside aboutDialog / howToDialog /
  updateChecker.
* Fixed: pitch slider in the per-channel FX panel was broken
  (the slider's valueChanged was wired but the resulting
  pitchFactor never reached the active InputFile). The
  ConfigModel -> Sampler -> InputFile chain now propagates
  pitch changes through setSlotPitchFactor exactly like speed.

---------------------------------------------------------------------
DSP SANDBOX
---------------------------------------------------------------------
* New: per-channel Random Pitch module in the DSP accordion area.
  Each play triggers a random offset within +/- a user-set range,
  baked into the InputFile's pitchFactor before open() so the
  variation is audible from the first sample.
* New: per-channel Sidechain Ducking module. When another channel
  is selected as the sidechain source, this channel's output is
  attenuated by the source's RMS envelope (attack / release
  user-controlled). Useful for VO-over-music cells.
* Both new modules respect the sandbox master ENABLED gate so
  the dialog's "Enabled" master switch correctly turns them off
  in one click.
* Sandbox dialog initial size 1240x940 -> 1360x1000 so the EQ
  column + DSP accordion both fit without scrolling on a
  1080p display. EQ band slider width tightened (22 -> 14 px)
  so the EQ column takes ~30% less horizontal space.

---------------------------------------------------------------------
HOUSEKEEPING
---------------------------------------------------------------------
* New: in-app "What's new" dialog shown once per version. Reads
  the changelog section for the running version from the
  embedded release-notes.txt resource.
* New: in-app log viewer dialog (Settings -> Diagnostics ->
  View log file). Streams rpsb_debug.log in real time so the
  user does not need to dig into %APPDATA% to share a log.
* New: file metadata module surfaces the audio file's actual
  sample rate / channel count / codec / duration in the cell
  editor tooltip, so the user can tell at a glance whether a
  cell will resample on play.
* Italian localisation refreshed (574 messages, all new strings
  translated).

GameBaiters Soundboard v2.2.7
=============================

Waveform-cursor coherency release on top of v2.2.6. Fixes a cluster of
bugs around how the playback cursor, crop markers, time label, and
end-of-playback interact when pitch / speed / loop are combined with a
start/end trim. New: multi-format export (WAV / FLAC / OGG Vorbis /
AAC-M4A). The export progress dialog was rewritten from scratch.

---------------------------------------------------------------------
WAVEFORM CURSOR & PLAYBACK COHERENCY
---------------------------------------------------------------------
* Fixed: cursor visually escaped the start/end crop markers when
  pitch or speed was modified. The cursor's pixel position is
  computed against the full file length; with a crop active the
  marker overlay covers the trimmed edges, but the cursor line
  itself was drawn unclipped, so it tracked past the visible end.
  The cursor and the played-portion tint are now clamped to the
  [cropStart, cropEnd] pixel range that the marker overlay defines.
* Fixed: cursor jumped forward / backward while the user dragged
  the speed slider during playback. Live speed changes recompute
  bufferedSec with the new speedFactor against samples that were
  produced at the OLD factor; the raw position therefore jumped
  on every tick. The cache refresh is now monotonic (rejects
  backward jumps from this artefact) and rate-limited to a
  comfortably-above-real-time forward advance per audio cycle.
  Explicit seeks / play / loop restarts invalidate the anchor so
  legitimate position jumps (user-driven backward seek, loop wrap)
  still snap immediately.
* Fixed: with loop + non-1.0 speed + a crop range, the cursor
  reached cropEnd and froze while the audio kept playing past it.
  InputFileFFmpeg::setMaxPlayTime stored its bound in OUTPUT
  samples but the input-to-output sample ratio depends on
  speedFactor, so a 10-second crop at speed 2 actually decoded
  20 seconds of input. The bound is now stored in INPUT-file
  seconds and compared against m_filePosition (which is also in
  input-time), so the decoder stops at the requested input second
  no matter how pitch / speed change during playback. Cursor,
  audio, loop restart, and time label now all agree on where the
  end is.
* Fixed: the waveform time label read elapsed seconds against the
  full file length (e.g. "12 s / 30 s") instead of against the
  active crop range. With a crop set it now reads
  "(pos - cropStart) / (cropEnd - cropStart)", matching what the
  cursor visually expresses and what the audio actually plays.

---------------------------------------------------------------------
EXPORT
---------------------------------------------------------------------
* New: multi-format export. The Export-audio dialog now offers
  WAV (PCM 16-bit), FLAC (lossless), OGG Vorbis, and AAC in M4A.
  Format is detected from the filename extension (or the
  selected filter). Unknown extensions fall back to WAV. The
  encoder is a thin FFmpeg-backed bridge that handles channel-
  layout / sample-format conversion via swresample so every
  format receives the same DSP-chain-applied stereo PCM stream.
* Fixed: the export progress dialog was broken - the bar stuck
  at 0% on Windows native style, the chunk fill leaked outside
  the rounded background, and the final 100% green / red state
  did not always render. The dialog now uses a custom-painted
  bar (rounded track, fill clipped to a rounded path, 60 Hz
  easing toward target) instead of QProgressBar + QSS chunks,
  so the visual is reliable across styles.
* The FFmpeg static recipe (Windows) and CI cache key both
  picked up new encoders / muxers (pcm_s16le, flac, vorbis,
  aac and wav, flac, ogg, ipod, mp4 muxers). build_local.ps1
  now writes a .recipe-version marker after each FFmpeg build
  and force-rebuilds when the recipe id changes, so a stale
  cached tree never silently misses new symbols.
* The Linux runner was bumped from ubuntu-22.04 to ubuntu-24.04
  so the system FFmpeg covers the encoder APIs the bridge
  needs (swr_alloc_set_opts2, av_channel_layout_default,
  AVFrame::ch_layout - all added in FFmpeg 5.1).

GameBaiters Soundboard v2.2.6
=============================

Performance and audio-quality release on top of v2.2.5. Eliminates
GUI lag at idle and during slider drags, fixes the residual frying
buzz on the Leia engine for complex audio, restores the strength of
the Classic 8D rotating engine, and reworks the ini-save policy so
settings are persisted on user events instead of a background timer
that itself caused recurring lag. New: the audio sandbox remembers
the chosen movement engine across sessions.

---------------------------------------------------------------------
PERFORMANCE
---------------------------------------------------------------------
* Fixed: system-wide GUI lag when the soundboard was loaded.
  Position polling now runs at 30 Hz instead of 60 Hz, skips
  silent slots via a lock-free atomic, and reads its data from a
  lock-free position cache updated by the audio thread - no
  mutex contention against the audio block.
* Fixed: any slider in the UI lagging behind the cursor while
  dragging. Every model setter used to perform a synchronous
  full-ini disk write on each valueChanged tick. Saves are now
  event-driven (see PERSISTENCE below).
* Fixed: 1-second audio + GUI freeze the first time the user
  picked the Leia engine. The SOFA file load + FFT plan build +
  noise probe calibration ran inside the audio mutex; it now
  runs outside the lock so audio keeps flowing through the
  Classic fallback while Leia initialises.
* Fixed: the audio thread holding m_mutex through fetchSamples
  at idle. Both audio paths now bail lock-free when no slot is
  playing, so the GUI sees the mutex completely uncontended
  with nothing happening.

---------------------------------------------------------------------
SPATIAL AUDIO
---------------------------------------------------------------------
* Fixed: residual frying buzz on the Leia engine with complex
  (broadband, high-peak) material like full songs. Three causes
  addressed together:
  - HRIR lookups widened from 0.5 deg to 3 deg deadband (well
    above the SOFA grid) so the audio thread no longer pays a
    full IR-FFT per block under rotation.
  - The live HRIR is now smoothed toward the latest lookup at
    a much slower rate (~270 ms to 95% vs the previous 27 ms).
    Each block's IR differs from the previous by a tiny amount
    so the OLA overlap adds nearly-coherently with the new
    convolution - the per-block click train that summed to a
    ~187 Hz tone is now well below the audible floor.
  - The post-Leia limiter no longer pumps on every rotational
    peak. Its ceiling was raised to 1.4 (SlotDsp's outer soft
    limiter at 1.0 still catches real overshoots), so the
    rotation-rate amplitude modulation that read as frying on
    complex material is gone.
* Fixed: rotating Leia sources also showed a finer "buzz" from
  the early-reflections engine. ShoeboxRoom now uses a per-
  sample fractional delay-line read that lerps the delay from
  the previous block to the new one across the block, instead
  of jumping the read offset stepwise every block (which was a
  zipper noise riding the reflection signal at block rate).
* Fixed: the Classic parametric 8D engine became significantly
  quieter after the v2.2.4 "boombox bass bump" fix. Rotating
  modes (3D Rotate, 8D preset) now use a wider-than-unity
  width compensation curve (1.4 at width 0 tapering to 1.0 at
  >=90 deg) - actually louder than the original pre-fix
  loudness, without the bass bump returning. 3D Manual keeps
  the original 0.5..1.0 curve since the bass bump only
  appeared on static, narrow-width sources.

---------------------------------------------------------------------
PERSISTENCE
---------------------------------------------------------------------
* Reworked: ini saves are now event-triggered rather than
  running on a background timer. The model is marked dirty
  on each setter call and the disk write fires from concrete
  user events:
  - Start of playback (sound, hotkey, preview)
  - Closing the soundboard window (Mainpage or legacy)
  - Hiding the soundboard window (TS3 tab switch)
  - Switching between the 4 soundboard profiles
  - Server disconnect
  - Plugin shutdown (TeamSpeak quit, plugin unload)
* Closing the soundboard window without quitting TS3 does NOT
  reset state - it flushes the in-memory model so the next
  open finds the most recent settings.
* The previous 250 ms auto-debouncer was itself a recurring
  lag source on slider drags (one disk write a few hundred
  milliseconds after every drag). The new policy issues at
  most one write per concrete user event.
* The model's destructor and an explicit "specific path"
  branch ensure no save is silently dropped on plugin teardown.

---------------------------------------------------------------------
SANDBOX
---------------------------------------------------------------------
* New: the audio sandbox now remembers the chosen movement
  engine (Classic / Leia) across sessions. Picking an engine
  in any channel's sandbox dialog persists the choice to a
  global QSettings key; freshly-added channels default to that
  engine instead of falling back to Classic. Per-channel
  persistence (when enabled in Settings) still overrides this
  on restore for that specific channel.

---------------------------------------------------------------------
METER
---------------------------------------------------------------------
* Fixed: the peak-hold marker on the channel meter no longer
  freezes mid-fall when a sound stops. The v2.2.5 silent-slot
  optimisation drained the meter exactly once on the falling
  edge instead of letting the marker animate back to floor.
  The 25 Hz meter timer now pumps every tick; the meter's own
  change-detect kills paints once the marker reaches rest.

GameBaiters Soundboard v2.2.5
=============================

Stability release on top of v2.2.4: three independent fixes to
TS3's transmission state. The mic no longer goes dead when you
release a held PTT mid-playback, voice activation no longer gets
stuck after a sound stops, and TeamSpeak no longer crashes on
close when the soundboard is active.

---------------------------------------------------------------------
TRANSMISSION STATE
---------------------------------------------------------------------
* Fixed: in a PTT channel, holding PTT before starting a sound
  and releasing it mid-playback no longer cuts the soundboard
  audio off for everyone else. A 150 ms watchdog now re-asserts
  continuous transmission if TS3's PTT-up handler steals it back.
* Fixed: voice activity detection stayed dead after a sound
  stopped, until the user mute/unmuted manually. The plugin now
  forces a VAD preprocessor re-init on restore (vad off then on),
  which is the programmatic equivalent of the manual workaround.
* Fixed: a fast play / pause / unpause / stop sequence could
  leave the mic permanently open after playback. A stale TS3
  state read was being captured as "the user's real talk mode",
  so the restore looped back to continuous transmission instead
  of PTT. Adds a sticky last-known-mode cache, rejects an
  obviously stale snapshot, and verifies the restored
  CLIENT_INPUT_DEACTIVATED actually took effect.

---------------------------------------------------------------------
STABILITY
---------------------------------------------------------------------
* Fixed: TeamSpeak crashing on close while the soundboard was
  active. On disconnect / shutdown the plugin was still writing
  CLIENT_INPUT_DEACTIVATED + flushClientSelfUpdates after TS3
  had begun tearing down its audio backend, hitting a NULL in
  directsound_win64.dll. The plugin now invalidates its TS3
  handle before any queued restore can fire.

GameBaiters Soundboard v2.2.4
=============================

Polish release on top of v2.2.3: fixes a frying buzz and rear-pass
jump in the new Leia engine, makes the elevation slider work in
every 3D mode, kills the duplicate error dialog, smooths the
waveform cursor, and adds right-click crop editing on the waveform.

---------------------------------------------------------------------
SPATIAL AUDIO
---------------------------------------------------------------------
* Fixed a faint "frying" buzz heard while the Leia engine was
  active. One output sample per block was being dropped, which
  produced a continuous ~187 Hz tone underneath the audio.
* Fixed the 8D preset on Leia jumping between ears when the
  source passed straight behind the head with reflections turned
  up. The reflection pan now uses a continuous curve through the
  rear so the sound circles smoothly all the way around.
* Hot Leia settings (high reflection level + clarity + width) no
  longer push the wet signal into a distorted, "earrape" overload.
  A soft post-engine limiter pulls sustained peaks down without
  pumping on the brief peaks of an orbiting source.

  and 8D) on both engines. It previously felt dead in the
  rotating modes because it wrote to the wrong field.

---------------------------------------------------------------------
WAVEFORM & PLAYBACK
---------------------------------------------------------------------
* New: right-click a channel's waveform to set a Start or End
  marker exactly at the click point, or right-click an existing
  marker to remove it. There is also a "Remove both markers"
  shortcut. Edits are saved back to the cell just like changing
  the crop in the cell's settings, and the change applies to the
  audio that is already playing - the cell truncates at the new
  end point instead of waiting for the next play.
* The cursor on the waveform is now much smoother and lands
  exactly where you click. Position updates at 60 Hz instead of
  20 Hz, the cursor snaps to the release point the instant you
  let go of the mouse, and the buffered span is now scaled by
  each slot's own speed factor so the cursor no longer drifts
  ahead of the audio on sped-up cells.

---------------------------------------------------------------------
INTERFACE
---------------------------------------------------------------------
* An unplayable file now shows a single, clear error dialog.
  Before this, two different "Playback failed" messages popped
  up back-to-back when a cell pointed at a missing or corrupt
  file.
* New strings ("Set start here", "Set end here", "Remove start
  marker", "Remove end marker", "Remove both markers") are also
  available in Italian.

GameBaiters Soundboard v2.1.2
=============================

Hotfix release on top of v2.1.1.

---------------------------------------------------------------------
WAV / PCM PLAYBACK FIX
---------------------------------------------------------------------
* WAV files (and other raw PCM-coded audio) now play correctly again.
  The container leaves the channel layout marked as "unspecified" with
  only the channel count populated; the v2.1.1 filter graph passed

---------------------------------------------------------------------
* macOS auto-update was downloading the Windows .ts3_plugin and trying
  to extract it - the install silently failed and the old plugin
  stayed in place. The updater now picks the correct .ts3_plugin
  artefact for the running OS (Windows / Linux / macOS) directly from
  the version manifest.
* macOS install helper now relaunches TeamSpeak 3 automatically after
  the new plugin is in place, surfaces a native success notification,
  and shows an actionable dialog with the download path if the
  install fails.

GameBaiters Soundboard v2.1.0
=============================

DSP pipeline overhaul: eight new real-time effects, draggable
pipeline reordering, per-module reset, and a critical pitch-shift
fix. Full changelog below; v2.0.0 notes follow after.

---------------------------------------------------------------------
NEW DSP EFFECTS
---------------------------------------------------------------------
* Compressor — threshold / ratio / attack / release / makeup gain.
* Saturator — soft / hard / tape / tube modes, drive + mix knobs.
* Chorus — rate / depth / mix, stereo widening via L/R phase offset.
* Flanger — rate / depth / feedback / mix, classic jet sweep.
* Flangus — dual-LFO flanger with cross-feedback for metallic tones.
* Phaser — 4-stage all-pass, rate / depth / feedback / mix.
* Delay — time / feedback / mix, stereo ping-pong mode, damping
  filter on the feedback path.
* Limiter — brick-wall look-ahead limiter at the end of the chain,
  ceiling / release controls.

All effects are per-channel, persist to disk, survive TS3 restarts,
and are bundled into macros.

---------------------------------------------------------------------
DRAGGABLE DSP PIPELINE
---------------------------------------------------------------------
* Visual pipeline widget at the top of the sandbox dialog shows all
  11 DSP stages as coloured blocks with arrows.
* Drag any block to reorder the processing chain in real time.
* Pipeline order persists per-channel (serialized in sandbox JSON).
* Default order: EQ > Compressor > Saturator > Chorus > Flanger >
  Flangus > Phaser > Delay > Positional > Reverb > Limiter.

---------------------------------------------------------------------
PER-MODULE RESET BUTTONS
---------------------------------------------------------------------
* Every DSP module header row now has a reset button (reload icon)
  that restores only that module's parameters to defaults without
  touching any other module.

---------------------------------------------------------------------
MASTER ENABLE GATING
---------------------------------------------------------------------
* The "Enable audio sandbox" checkbox now properly disables the
  entire DSP group box. When unchecked, NO sandbox effects are
  applied — only the FxPanel reverb (which lives outside the
  sandbox) passes through.

---------------------------------------------------------------------
LAYOUT SWAP
---------------------------------------------------------------------
* Sandbox dialog left column: EQ + Spatial/3D positioning.
* Sandbox dialog right column: Paulstretch + DSP modules.
  (Previously EQ was on the right.)

---------------------------------------------------------------------
BUG FIXES
---------------------------------------------------------------------
* Fix pitch slider freezing audio permanently. Root cause: the
  FFmpeg static build does not include the `asetrate` filter. Pitch
  shift now works via abuffer sample-rate override + aresample,
  requiring only filters already compiled in (aresample + atempo).
* Fix ping-pong delay: both channels were receiving dry input.
  Now mono-summed input feeds the left delay line only; right line
  receives only the cross-feedback signal.
* Fix sandbox bypass: toggling "Enable audio sandbox" OFF while
  FxPanel reverb was active still ran all sandbox DSP stages.
  Pipeline loop now skips non-reverb stages when sandbox is disabled.

---------------------------------------------------------------------
CODE CLEANUP
---------------------------------------------------------------------
* Debug file logging (RPSB_FILE_DEBUG) disabled for release builds.
* Removed dead commented-out code blocks across plugin.cpp,
  ConfigModel.cpp, SampleBuffer.cpp/h, about_qt.cpp.
* Removed stale TODO comments and leftover printf debug output.

GameBaiters Soundboard v2.0.0
=============================

Major release. Plugin rebuilt around a modular UI, a per-channel
audio sandbox (HRTF / EQ / Paulstretch / room reverb), and a long
list of stability + quality fixes accumulated since the last 1.x
build.

---------------------------------------------------------------------
NEW UI
---------------------------------------------------------------------
* Brand-new MainPage layout. Search bar on top, button grid in the
  middle, scrollable channel area below, transport / mute / settings
  bar at the bottom.
* Modular per-channel widget: editable title, drag-source for sound
  buttons, volume control with Local / Remote sliders + 1:1 link
  toggle, FX panel (pitch / speed / reverb + sync), waveform with
  click-seek + skip buttons, dual-LR meter, and the new "Spatial /
  EQ / Stretch" sandbox button.
* Settings is a separate, scrollable window with grouped sections:
  Audio engine, Channels, Button grid, Hotkeys, Logging, Audio
  sandbox, Profiles, Custom theme, Configuration import/export.
* Dark stylesheet is scoped under [isGBSoundboard="true"] and
  bracketed inside a marked block on qApp so it co-exists with the
  host TS3 client's own qApp stylesheet without clobbering it.
* Help bubbles ("?" badge widgets) on every non-obvious control with
  long-form descriptions.

---------------------------------------------------------------------
PER-CHANNEL AUDIO SANDBOX
---------------------------------------------------------------------
The "Spatial / EQ / Stretch" button on each channel opens a per-slot
DSP dialog. Settings persist between TS3 restarts and are bundled
into Macros.

* Master "Enable audio sandbox on this channel" switch. When OFF the
  whole DSP chain is bypassed (zero CPU cost) and every sub-control
  in the dialog is disabled.
* Spatial mode dropdown:
    - Off (no spatial)
    - L/R Pan: equal-power balance
    - 3D Manual: drag a virtual source on the XY pad with elevation,
      distance, stereo width, head sway
    - 3D Rotate: source orbits around the head at a chosen RPM and
      radius (CW / CCW)
    - 3D 8D Preset: orbit + tight stereo width + head sway + room
      ambience tuned to match the audio_sandbox standalone reference
* Brown-Duda structural HRTF, dual virtual-speaker rendering. ITD
  via Woodworth (up to 656 us), 1p/1z head shadow, 5-event sparse
  pinna FIR, shoulder + torso single-tap reflections, peaking notch
  for front/back, concha boost at 3 kHz, head-sway LFO, distance
  attenuation + air absorption shelf.
* "Spatial mix" slider blends the HRTF output with the raw stereo
  input - matches the audio_sandbox standalone reference and stops
  the source from feeling mono / over-coloured.
* Room "Ambience" reverb (Schroeder-Moorer / Freeverb topology, 8
  combs + 4 allpasses per channel). Independent from the FxPanel
  reverb - this one shapes SPACE, FxPanel shapes the SOUND.
* 16-band ISO 2/3-octave graphic EQ (-12..+12 dB, Q matched to band
  spacing, anti-denormal protection, master "Enable EQ" toggle, big
  step changes reset filter state to kill cascading transients).
* Paulstretch (Paul Nasca's phase-randomisation extreme time-stretch).
  Streaming-adapted: feeds from the live decoder ring at decode rate
  while the synth stage advances slowly via FFT phase scrambling.
  Per-path (capture + playback) instances so the stretched output
  reaches BOTH the local listener and the server, in sync with each
  channel's seek / skip / stop / restart events. Adjustable factor
  1x..50x and window 50..1000 ms.
* "3D 8D Preset" mode auto-loads tuned values (rotate 10 RPM, stereo
  width 0, head sway on, ambience 12 %, spatial mix 85 %) for the
  classic YouTube-style 8D listening experience.
* "Reset audio sandbox for this channel" red button restores
  defaults for that single channel.

---------------------------------------------------------------------
PER-CHANNEL METER
---------------------------------------------------------------------
* Two-row L/R LED-style meter at the centre of each channel. 96
  segments (~0.4 dB resolution), cyan -> amber -> red colour ramp,
  red flashing border on clip. Reflects the post-DSP, post-Remote-
  volume signal so it always shows what the SERVER hears regardless
  of the local playback slider.
* Settings switch "Show audio meter on each channel" hides it for
  users who don't want it.
* Slot peak resets to zero when the slot stops, finishes, or is
  cleared - no more frozen levels.

THEME ENGINE

  recolours every surface, border, hover, disabled state and
  contrast-flips the text.
* "Auto" buttons next to Text and Buttons revert to the auto-derived

  of a placeholder grey.
* Copy theme / Paste theme produce a single share string (GBSB1..4)

* Theme block on qApp is bracketed by /*RPSB-BLOCK-START*/ ..
  /*RPSB-BLOCK-END*/ markers so the soundboard never clobbers TS3's

SETTINGS WINDOW

HOTKEYS / TRANSMISSION

WAVEFORM + TRANSPORT
---------------------------------------------------------------------

  - subtracts the queued sb ring duration so a freshly-started
  7-second clip starts the slider at 0 instead of at 70 %.
* Seek + skip + stop + new-play all reset the per-slot DSP state
  (EQ + Positional + Reverb + Paulstretch ring) so paulstretch
  restarts cleanly on every transport event instead of staying
  seconds behind.

---------------------------------------------------------------------
DSP PIPELINE
---------------------------------------------------------------------
Per-slot pipeline order, applied independently to capture (server)
and playback (local) so each side keeps its own filter state:

    decoder (FFmpeg, libavfilter pitch / speed)
        v
    sb ring (capture + playback)
        v
    Paulstretch (streaming, dual-instance, optional)
        v
    EQ 16-band (master Enable EQ + per-band gain)
        v
    Spatial: Off / L-R Pan / HRTF dual virtual speaker
        v
    Wet/dry crossfade with raw stereo (Spatial mix)
        v
    Reverb (Ambience + FxPanel reverb summed; END of pipeline)
        v
    Soft limiter (tanh past 0.95)
        v
    int16 clamp + per-slot volume scaling
        v
    PeakMeter limit (legacy earrape protection)
        v
    output

* FxPanel reverb relocated from libavfilter at the decoder to the
  end of the per-slot DSP chain (when sandbox is active) so it
  sounds like a real "room" effect after spatial / EQ.
* Anti-denormal injection at the top of the per-sample loop keeps
  every IIR cascade above the float subnormal floor - eliminates
  the robotic background hiss that used to surface on 8D mode over
  silent intros.
* Soft limiter tightened to T=0.95 with a strict bound at +/-1.0.

---------------------------------------------------------------------
PERSISTENCE
---------------------------------------------------------------------
* Per-channel state (link, sync, sandbox, name) ALWAYS persists to
  disk regardless of the "Restore last session" setting.
* "Restore last session" still controls whether saved channel COUNT
  and the auto-load of files into those channels happens at boot.
* Macros now bundle each channel's full sandbox state.
* Sandbox state migrates cleanly through the JSON serializer so
  older configs without the new fields load with sensible defaults.

NOTABLE BUG FIXES SINCE 1.0.x
---------------------------------------------------------------------
* Theme leak: opening the soundboard no longer wipes TS3's host
  qApp stylesheet - the theme is bracketed and append-merged.
* Drag-swap of grid cells no longer crashes (deferred via QTimer
  singleShot so the drop event finishes before the model rebuild).
* Sound-button cells respect their custom colour + theme palette
  without flipping to opaque black on Qt 5.15.2 (QColor() invalid
  alpha=255 trap).
* HSL adjustL clamps h>=0 so achromatic / grey pickers don't
  collapse the derived palette to pure black.
* Per-deep-widget refreshTheme on FxPanel + VolumeControl + Channel
  so QSS cascade misses don't leave sliders un-themed.
* Reset Channels properly de-greens the link / sync toggle buttons
  the first time (refreshTheme now always runs after setLinked /
  setSync, even when the value already matches).
* PeakMeter no longer compresses every transient on DSP-active
  slots - the limiter still protects against earrape but the main
  quality drop reported as "compressed YouTube" is gone.
* Robotic transient on toggling "Mute on my client" (or any
  capture / playback enable change) eliminated by giving each path
  its own EQ + Positional + Reverb state.
* Robotic burst on starting a new sound on a sandbox-active slot
  eliminated by resetting per-slot DSP state in playSoundInSlot.
* Robotic burst on activating 3D mode eliminated by snapping
  Positional smoothers to target on reset, resetting PathState on
  spatial-mode transitions, and guarding Reverb buffer realloc
  against same-rate setSampleRate calls.
