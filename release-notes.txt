GameBaiters Soundboard 1.0.119
==============================

Bugfixes
--------
* Windows: WAV files now play correctly. The static FFmpeg build was
  missing several PCM decoders (pcm_u8, pcm_s16be, pcm_u16le/be,
  pcm_f64le, pcm_alaw, pcm_mulaw). A WAV encoded with any of these
  codecs would fail with "avcodec_find_decoder returned NULL" and
  never produce audio. All common PCM variants are now enabled.

* Windows: plugin and auto-updater no longer hardcode
  %APPDATA%\TS3Client as the TeamSpeak config directory. If TS3 is
  installed to a custom location the plugin now asks TS3 for the
  actual config path via getConfigPath() at runtime, with fallback
  to %APPDATA%\TS3Client for compatibility. This affects:
    - Debug log (rpsb_debug.log) written to the correct TS3 dir
    - Plugin uninstall (Settings > Plugins > Uninstall) cleaning
      the correct plugin assets folder
    - Auto-update helper script deleting old DLLs from the correct
      plugins folder

* Windows uninstaller (uninstall_soundboard.bat) now accepts an
  optional argument for custom TS3 config paths:
    uninstall_soundboard.bat "D:\Games\TS3Client"
  Without an argument it defaults to %APPDATA%\TS3Client as before.

macOS unchanged
---------------
None of the above changes affect macOS. The macOS code paths
(debug log, updater, codesign) are untouched.

Carried over from 1.0.118
-------------------------
* Windows: pitch / speed sliders fixed (atempo + asetrate enabled
  in the static FFmpeg build).
* Per-platform .ts3_plugin packages (no more macOS dylibs in
  Windows installs).
* Windows uninstaller sweeps macOS dylib leftovers from older
  multi-platform installs.

Carried over from 1.0.117
-------------------------
* macOS: best-effort dual API for abuffersink format constraints
  (FFmpeg 8 renamed sample_fmts -> sample_formats).

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots)

Installation
------------

* Windows: download rp_soundboard_fx_<version>_win64.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, RIGHT-CLICK
  Install Soundboard.app -> Open the first time so macOS Gatekeeper
  accepts the ad-hoc signature.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts in the release assets keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
