GameBaiters Soundboard 1.0.20 - gamebaiters branch release
============================================================

Bug fixes
---------
* Fixed: TeamSpeak Settings -> Plugins -> Uninstall now actually deletes
  the plugin DLL. The singleton SampleVisualizerThread that powered the
  realtime waveform was never stopped during plugin shutdown - its still-
  running std::thread held DLL code in memory, so FreeLibrary failed
  silently and the file stayed locked.
  - Hard-stop the visualizer thread before tearing down the sampler
  - Drain the Qt event queue (DeferredDelete + processEvents) so
    QNetworkReply / QTimer slots cannot fire into unloaded code
  - Close the rpsb_debug.log file handle on shutdown
  - Hide + reparent ConfigQt and AboutQt dialogs synchronously
* Auto-updater now uninstalls the previous version cleanly. The
  downloaded .ts3_plugin is no longer handed straight to package_inst -
  a small helper batch is written to %TEMP% that:
    1. Closes any running TeamSpeak 3 client
    2. Removes every prior plugin DLL variant
       (rp_soundboard_fx_win{32,64}.dll, rp_soundboard_win{32,64}.dll,
        rp_soundboard.dll)
    3. Hands the new .ts3_plugin to package_inst.exe via file association
  The user's rp_soundboard.ini config is preserved across the update.
* Plugin startup now sweeps legacy upstream DLLs from
  %APPDATA%\TS3Client\plugins\ on init, so an old MGraefe build can no
  longer coexist with the GameBaiters fork.

UI tweaks
---------
* +5s / -5s / +10s / -10s skip buttons widened (44-56 px) and font bumped
  to 9pt - labels are now fully readable in both the main window and the
  multi-soundboard slot bars.
* Dark theme restored. dark_style.qss is bundled and applied in About,
  Audio Effects, Config, Sound Settings and Updater dialogs.

Uninstall script
----------------
* uninstall_soundboard.bat / .sh / _macos.sh now offer a 3-way backup
  prompt: [F]ull, [C]onfig only, or [N]o backup. The script no longer
  exits on its own - a final pause keeps the window open so you can read
  the result.

Existing GameBaiters features (carried from 1.0.18)
---------------------------------------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection (local hard-limiter)
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots playing concurrently)
* Update channel served from this gamebaiters branch on GitHub
