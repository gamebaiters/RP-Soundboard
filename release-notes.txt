GameBaiters Soundboard v2.2.3
=============================

Adds a brand-new spatial audio engine you can switch to per
channel, fixes the 8D preset bass blow-out and tidies up the
Audio Sandbox window.

---------------------------------------------------------------------
NEW SPATIAL ENGINE
---------------------------------------------------------------------
* New "Leia" HRTF engine - convolution with a measured
  head-related transfer dataset plus real room reflections. It
  gives correct front/back positioning and a far more convincing
  sense of space than the original parametric engine.
* The 3D HRTF section now has an engine selector: Classic or
  Leia. The choice is saved per channel and stored in presets,
  so you can A/B the two engines on the same sound.
* Leia adds room controls: early reflections on/off, reflection
  level, room size, room type (Drapes / Studio / Tiles /
  Concrete / Glass), clarity and width.
* The 8D preset and the auto-rotate modes work with both
  engines.
* If the Leia data cannot load, playback falls back to the
  Classic engine automatically - audio is never interrupted.

---------------------------------------------------------------------
SPATIAL AUDIO FIXES
---------------------------------------------------------------------
* Fixed the 8D preset (and other narrow-width 3D modes) blowing
  out the bass into a distorted, rotating "boombox" effect.

---------------------------------------------------------------------
INTERFACE
---------------------------------------------------------------------
* Every spatial control now lives in one fixed-size, separately
  scrollable panel - no more scrolling the whole window to reach
  an option, and the controls always fit horizontally.
* The Audio Sandbox window now opens at a size that fits the
  screen instead of needing to be resized first.

  window no longer freezes playback. The synthesis threshold was

  works correctly. The decoder's done-flag was not being reset on

---------------------------------------------------------------------
* Redesigned About dialog with proper dark theme support, plugin
  icon, and corrected project links.
* Easter egg: progressive sun animation (yellow -> orange -> red)
  leading into a blue supernova explosion with smooth reset.

CODE CLEANUP

GameBaiters Soundboard v2.1.2
=============================

Hotfix release on top of v2.1.1.

---------------------------------------------------------------------
WAV / PCM PLAYBACK FIX
---------------------------------------------------------------------
* WAV files (and other raw PCM-coded audio) now play correctly again.
  The container leaves the channel layout marked as "unspecified" with
  only the channel count populated; the v2.1.1 filter graph passed
  that label through verbatim and downstream filters then dropped
  every decoded frame, so playback ran silently. The layout is now
  normalised to a real stereo / mono mask before the filter chain so
  every audio path matches.

---------------------------------------------------------------------
MACOS AUTO-UPDATER
---------------------------------------------------------------------
* macOS auto-update was downloading the Windows .ts3_plugin and trying
  to extract it - the install silently failed and the old plugin
  stayed in place. The updater now picks the correct .ts3_plugin
  artefact for the running OS (Windows / Linux / macOS) directly from
  the version manifest.
* macOS install helper now relaunches TeamSpeak 3 automatically after
  the new plugin is in place, surfaces a native success notification,
  and shows an actionable dialog with the download path if the
  install fails.

GameBaiters Soundboard v2.1.1
=============================

reported around the sandbox / macro / profile / export flows and

---------------------------------------------------------------------
SANDBOX FIXES
---------------------------------------------------------------------

* Switching profiles no longer wipes per-channel sandbox state. The
  state is flushed to persistence before the switch and re-applied

* Resetting the sandbox or switching channels now correctly re-pushes
  the sandbox state to the sampler so DSP follows the UI live.

---------------------------------------------------------------------
MACRO RESTORE
---------------------------------------------------------------------
* "Restore pre-macro" button now actually reloads the channel state
  that was active before the macro fired. The pre-macro snapshot
  captures live playback position from the sampler so each channel
  resumes at the exact second the macro was triggered. Audio reloads
  paused so the user can resume manually.

---------------------------------------------------------------------
EXPORT FLOW
---------------------------------------------------------------------
* Export button now uses a text-only label with a fixed compact size
  so it no longer stretches the channel row taller than the other
  controls. The previous mismatched stop-arrow icon was removed.
* Crash on Export click resolved. The exporter is hardened against
  malformed inputs (heap-allocated DSP, file existence pre-check,
  per-thread try/catch, clean QThread::finished teardown).
* Export now bakes the FULL live signal chain into the WAV:
  - pitch / speed / reverb from the channel FX panel,
  - every active sandbox stage (EQ / spatial / compressor / chorus
    / flanger / flangus / phaser / saturator / delay / room reverb
    / limiter),
  - Paulstretch time-stretch when enabled,
  - in the exact pipeline order the user dragged in the sandbox
    dialog.
* New floating progress card. Themed glyph + bar + live percentage
  while encoding; morphs into a success / failure card at the end
  with a clean dismiss button. Cancel mid-encode is honoured.

---------------------------------------------------------------------
CHANNEL LAYOUT
---------------------------------------------------------------------
* Single channel with all features enabled (waveform + transport +
  sandbox + export + meter) no longer triggers a vertical scrollbar.
  The channel area now sizes itself to fit the actual content; the
  scrollbar only appears once enough channels are stacked to justify
  it. The grey dead space below the last channel is gone.
* Soundboard window is now resizable down to a small docked strip
  (480×320). Button grid + channel area both shrink gracefully.

---------------------------------------------------------------------
PLAYBACK ROBUSTNESS
---------------------------------------------------------------------
* Defensive validation against malformed codec parameters before
  the decoder is fully opened, so a corrupt audio file no longer
  has a chance to take down the TeamSpeak client.
* Source PCM parameters (sample rate, channel layout) are now read
  authoritatively from the container's codec parameters; this fixes
  rare cases where playback silently failed with no audible output.

---------------------------------------------------------------------
LOGGING
---------------------------------------------------------------------
* Debug log file ("Write debug log file" in Settings > Logging) now
  actually writes when enabled. The compile-time gate that silently
  skipped every log line in release builds has been lifted; the

---------------------------------------------------------------------
INTERNAL CLEANUP
---------------------------------------------------------------------
* Misc consistency fixes around channel state persistence on
  add / remove / profile switch.
* Tightened lifetime management in the audio exporter worker thread.

GameBaiters Soundboard v2.1.0
=============================

DSP pipeline overhaul: eight new real-time effects, draggable
pipeline reordering, per-module reset, and a critical pitch-shift
fix. Full changelog below; v2.0.0 notes follow after.

---------------------------------------------------------------------
NEW DSP EFFECTS
---------------------------------------------------------------------
* Compressor — threshold / ratio / attack / release / makeup gain.
* Saturator — soft / hard / tape / tube modes, drive + mix knobs.
* Chorus — rate / depth / mix, stereo widening via L/R phase offset.
* Flanger — rate / depth / feedback / mix, classic jet sweep.
* Flangus — dual-LFO flanger with cross-feedback for metallic tones.
* Phaser — 4-stage all-pass, rate / depth / feedback / mix.
* Delay — time / feedback / mix, stereo ping-pong mode, damping
  filter on the feedback path.
* Limiter — brick-wall look-ahead limiter at the end of the chain,
  ceiling / release controls.

All effects are per-channel, persist to disk, survive TS3 restarts,
and are bundled into macros.

---------------------------------------------------------------------
DRAGGABLE DSP PIPELINE
---------------------------------------------------------------------
* Visual pipeline widget at the top of the sandbox dialog shows all
  11 DSP stages as coloured blocks with arrows.
* Drag any block to reorder the processing chain in real time.
* Pipeline order persists per-channel (serialized in sandbox JSON).
* Default order: EQ > Compressor > Saturator > Chorus > Flanger >
  Flangus > Phaser > Delay > Positional > Reverb > Limiter.

---------------------------------------------------------------------
PER-MODULE RESET BUTTONS
---------------------------------------------------------------------
* Every DSP module header row now has a reset button (reload icon)
  that restores only that module's parameters to defaults without
  touching any other module.

---------------------------------------------------------------------
MASTER ENABLE GATING
---------------------------------------------------------------------
* The "Enable audio sandbox" checkbox now properly disables the
  entire DSP group box. When unchecked, NO sandbox effects are
  applied — only the FxPanel reverb (which lives outside the
  sandbox) passes through.

---------------------------------------------------------------------
LAYOUT SWAP
---------------------------------------------------------------------
* Sandbox dialog left column: EQ + Spatial/3D positioning.
* Sandbox dialog right column: Paulstretch + DSP modules.
  (Previously EQ was on the right.)

---------------------------------------------------------------------
BUG FIXES
---------------------------------------------------------------------
* Fix pitch slider freezing audio permanently. Root cause: the
  FFmpeg static build does not include the `asetrate` filter. Pitch
  shift now works via abuffer sample-rate override + aresample,
  requiring only filters already compiled in (aresample + atempo).
* Fix ping-pong delay: both channels were receiving dry input.
  Now mono-summed input feeds the left delay line only; right line
  receives only the cross-feedback signal.
* Fix sandbox bypass: toggling "Enable audio sandbox" OFF while
  FxPanel reverb was active still ran all sandbox DSP stages.
  Pipeline loop now skips non-reverb stages when sandbox is disabled.

---------------------------------------------------------------------
CODE CLEANUP
---------------------------------------------------------------------
* Debug file logging (RPSB_FILE_DEBUG) disabled for release builds.
* Removed dead commented-out code blocks across plugin.cpp,
  ConfigModel.cpp, SampleBuffer.cpp/h, about_qt.cpp.
* Removed stale TODO comments and leftover printf debug output.

GameBaiters Soundboard v2.0.0
=============================

Major release. Plugin rebuilt around a modular UI, a per-channel
audio sandbox (HRTF / EQ / Paulstretch / room reverb), and a long
list of stability + quality fixes accumulated since the last 1.x
build.

---------------------------------------------------------------------
NEW UI
---------------------------------------------------------------------
* Brand-new MainPage layout. Search bar on top, button grid in the
  middle, scrollable channel area below, transport / mute / settings
  bar at the bottom.
* Modular per-channel widget: editable title, drag-source for sound
  buttons, volume control with Local / Remote sliders + 1:1 link
  toggle, FX panel (pitch / speed / reverb + sync), waveform with
  click-seek + skip buttons, dual-LR meter, and the new "Spatial /
  EQ / Stretch" sandbox button.
* Settings is a separate, scrollable window with grouped sections:
  Audio engine, Channels, Button grid, Hotkeys, Logging, Audio
  sandbox, Profiles, Custom theme, Configuration import/export.
* Dark stylesheet is scoped under [isGBSoundboard="true"] and
  bracketed inside a marked block on qApp so it co-exists with the
  host TS3 client's own qApp stylesheet without clobbering it.
* Help bubbles ("?" badge widgets) on every non-obvious control with
  long-form descriptions.

---------------------------------------------------------------------
PER-CHANNEL AUDIO SANDBOX
---------------------------------------------------------------------
The "Spatial / EQ / Stretch" button on each channel opens a per-slot
DSP dialog. Settings persist between TS3 restarts and are bundled
into Macros.

* Master "Enable audio sandbox on this channel" switch. When OFF the
  whole DSP chain is bypassed (zero CPU cost) and every sub-control
  in the dialog is disabled.
* Spatial mode dropdown:
    - Off (no spatial)
    - L/R Pan: equal-power balance
    - 3D Manual: drag a virtual source on the XY pad with elevation,
      distance, stereo width, head sway
    - 3D Rotate: source orbits around the head at a chosen RPM and
      radius (CW / CCW)
    - 3D 8D Preset: orbit + tight stereo width + head sway + room
      ambience tuned to match the audio_sandbox standalone reference
* Brown-Duda structural HRTF, dual virtual-speaker rendering. ITD
  via Woodworth (up to 656 us), 1p/1z head shadow, 5-event sparse
  pinna FIR, shoulder + torso single-tap reflections, peaking notch
  for front/back, concha boost at 3 kHz, head-sway LFO, distance
  attenuation + air absorption shelf.
* "Spatial mix" slider blends the HRTF output with the raw stereo
  input - matches the audio_sandbox standalone reference and stops
  the source from feeling mono / over-coloured.
* Room "Ambience" reverb (Schroeder-Moorer / Freeverb topology, 8
  combs + 4 allpasses per channel). Independent from the FxPanel
  reverb - this one shapes SPACE, FxPanel shapes the SOUND.
* 16-band ISO 2/3-octave graphic EQ (-12..+12 dB, Q matched to band
  spacing, anti-denormal protection, master "Enable EQ" toggle, big
  step changes reset filter state to kill cascading transients).
* Paulstretch (Paul Nasca's phase-randomisation extreme time-stretch).
  Streaming-adapted: feeds from the live decoder ring at decode rate
  while the synth stage advances slowly via FFT phase scrambling.
  Per-path (capture + playback) instances so the stretched output
  reaches BOTH the local listener and the server, in sync with each
  channel's seek / skip / stop / restart events. Adjustable factor
  1x..50x and window 50..1000 ms.
* "3D 8D Preset" mode auto-loads tuned values (rotate 10 RPM, stereo
  width 0, head sway on, ambience 12 %, spatial mix 85 %) for the
  classic YouTube-style 8D listening experience.
* "Reset audio sandbox for this channel" red button restores
  defaults for that single channel.

---------------------------------------------------------------------
PER-CHANNEL METER
---------------------------------------------------------------------
* Two-row L/R LED-style meter at the centre of each channel. 96
  segments (~0.4 dB resolution), cyan -> amber -> red colour ramp,
  red flashing border on clip. Reflects the post-DSP, post-Remote-
  volume signal so it always shows what the SERVER hears regardless
  of the local playback slider.
* Settings switch "Show audio meter on each channel" hides it for
  users who don't want it.
* Slot peak resets to zero when the slot stops, finishes, or is
  cleared - no more frozen levels.

---------------------------------------------------------------------
THEME ENGINE
---------------------------------------------------------------------
* Custom theme group with five colour pickers (Background, Accent,
  Waveform, Text, Buttons) plus a Contrast slider 0..100 that scales
  every auto-derived shade.
* Per-token retint of dark_style.qss - every hex literal in the QSS
  is mapped through the derived palette so picking a new background
  recolours every surface, border, hover, disabled state and
  contrast-flips the text.
* "Auto" buttons next to Text and Buttons revert to the auto-derived
  values; the swatch shows what the auto value resolved to instead
  of a placeholder grey.
* Copy theme / Paste theme produce a single share string (GBSB1..4)
  carrying every colour + the contrast number so a friend can paste
  it and load the exact same look in one click.
* Theme block on qApp is bracketed by /*RPSB-BLOCK-START*/ ..
  /*RPSB-BLOCK-END*/ markers so the soundboard never clobbers TS3's
  own qApp stylesheet.

---------------------------------------------------------------------
SETTINGS WINDOW
---------------------------------------------------------------------
* Audio: master switch for custom FX (pitch / speed / reverb),
  earrape protection.
* Channels: link new-channel inheritance, remember pitch / speed /
  reverb per channel, hide waveforms (compact view), restore last
  session.
* Button grid: rows / columns spinners.
* Hotkeys: "Show hotkeys on buttons", "Disable hotkeys", "Reset all
  hotkeys" red button.
* Logging: opt-in debug log (rpsb_debug.log) under TS3's config dir.
  Default OFF so a fresh install never writes to disk.
* Audio sandbox: master enable, "Show audio meter on each channel",
  "Reset all audio sandbox settings" red button.
* Profiles: dropdown of 4 independent profiles + Export / Import
  per-profile to legacy .ini files.
* Configuration: full export / import (every profile, every macro,
  every setting) as wrapped JSON or legacy .ini.

---------------------------------------------------------------------
BUTTON GRID + MACROS
---------------------------------------------------------------------
* Drag a sound button onto another to swap their contents.
* Drag a file from Explorer onto a button to load that audio.
* Right-click context menu: Set hotkey, Reset hotkey, Clear, Edit,
  Make macro from current channels, Paste / Copy.
* Macros snapshot every visible channel's name + state + live
  playback position - including sandbox settings - so re-playing a
  macro restores the exact session.
* Custom button colours, custom text, custom button image (stretched
  over the button face with a translucent backdrop behind the
  label).
* Color swatch chip in the per-button advanced dialog shows the
  currently picked colour at a glance.

---------------------------------------------------------------------
PER-CHANNEL CONTROLS
---------------------------------------------------------------------
* "+ Add channel" / "Reset channels" buttons on the bottom bar.
* Per-channel controls survive a TS3 restart (link / sync state,
  sandbox config). Channel-count restore stays gated by "Restore
  last session".
* Reset Channels button clears link + sync state on the primary
  channel without leaving stale green highlights on the toggle
  buttons.
* Channel widgets refresh their themed inline stylesheets when the
  active theme changes.
* Channel removal stops the slot's playback first so audio + UI
  tear down together.

---------------------------------------------------------------------
PREVIEW-ONLY MODE
---------------------------------------------------------------------
* New "Preview only (server hears nothing)" checkbox on the bottom
  bar. With it ON the soundboard stays audible locally but the
  server only hears the user's mic - useful to test or rehearse a
  sound before broadcasting.
* TalkStateManager respects the flag in real time: toggling preview
  on while a sound is playing immediately restores TS3's original
  talk-state, and toggling off mid-sound re-arms continuous
  transmission.
* sb_handleCaptureData drains the sampler ring into a scratch buffer
  in preview mode - keeps state-machine + ring fill in sync without
  ever modifying the captured mic samples.

---------------------------------------------------------------------
HOTKEYS / TRANSMISSION
---------------------------------------------------------------------
* Per-button hotkey assign / reset via the advanced dialog.
* Globally enable / disable plugin hotkey handling.
* "Reset all hotkeys" wipes every saved binding (TS3-side bindings
  remain in TS3's own profile until cleared there).
* TalkStateManager ensures TS3 transmits while a sound is playing
  (when not in preview-only mode) and restores the previous state
  when the last slot stops.

---------------------------------------------------------------------
WAVEFORM + TRANSPORT
---------------------------------------------------------------------
* Click on the waveform to seek; -10s / -5s / +5s / +10s skip
  buttons; play / stop / pause-all / stop-all transport.
* Slider position is the AUDIBLE position, not the decoder position
  - subtracts the queued sb ring duration so a freshly-started
  7-second clip starts the slider at 0 instead of at 70 %.
* Seek + skip + stop + new-play all reset the per-slot DSP state
  (EQ + Positional + Reverb + Paulstretch ring) so paulstretch
  restarts cleanly on every transport event instead of staying
  seconds behind.

---------------------------------------------------------------------
DSP PIPELINE
---------------------------------------------------------------------
Per-slot pipeline order, applied independently to capture (server)
and playback (local) so each side keeps its own filter state:

    decoder (FFmpeg, libavfilter pitch / speed)
        v
    sb ring (capture + playback)
        v
    Paulstretch (streaming, dual-instance, optional)
        v
    EQ 16-band (master Enable EQ + per-band gain)
        v
    Spatial: Off / L-R Pan / HRTF dual virtual speaker
        v
    Wet/dry crossfade with raw stereo (Spatial mix)
        v
    Reverb (Ambience + FxPanel reverb summed; END of pipeline)
        v
    Soft limiter (tanh past 0.95)
        v
    int16 clamp + per-slot volume scaling
        v
    PeakMeter limit (legacy earrape protection)
        v
    output

* FxPanel reverb relocated from libavfilter at the decoder to the
  end of the per-slot DSP chain (when sandbox is active) so it
  sounds like a real "room" effect after spatial / EQ.
* Anti-denormal injection at the top of the per-sample loop keeps
  every IIR cascade above the float subnormal floor - eliminates
  the robotic background hiss that used to surface on 8D mode over
  silent intros.
* Soft limiter tightened to T=0.95 with a strict bound at +/-1.0.

---------------------------------------------------------------------
PERSISTENCE
---------------------------------------------------------------------
* Per-channel state (link, sync, sandbox, name) ALWAYS persists to
  disk regardless of the "Restore last session" setting.
* "Restore last session" still controls whether saved channel COUNT
  and the auto-load of files into those channels happens at boot.
* Macros now bundle each channel's full sandbox state.
* Sandbox state migrates cleanly through the JSON serializer so
  older configs without the new fields load with sensible defaults.

---------------------------------------------------------------------
LOGGING
---------------------------------------------------------------------
* Single rpsb_debug.log in the TS3 config folder. Default OFF.
* Toggle in Settings > Logging flips an in-process gate immediately
  so subsequent samples / inputfileffmpeg writes honour the
  preference without a plugin restart.

---------------------------------------------------------------------
NOTABLE BUG FIXES SINCE 1.0.x
---------------------------------------------------------------------
* Theme leak: opening the soundboard no longer wipes TS3's host
  qApp stylesheet - the theme is bracketed and append-merged.
* Drag-swap of grid cells no longer crashes (deferred via QTimer
  singleShot so the drop event finishes before the model rebuild).
* Sound-button cells respect their custom colour + theme palette
  without flipping to opaque black on Qt 5.15.2 (QColor() invalid
  alpha=255 trap).
* HSL adjustL clamps h>=0 so achromatic / grey pickers don't
  collapse the derived palette to pure black.
* Per-deep-widget refreshTheme on FxPanel + VolumeControl + Channel
  so QSS cascade misses don't leave sliders un-themed.
* Reset Channels properly de-greens the link / sync toggle buttons
  the first time (refreshTheme now always runs after setLinked /
  setSync, even when the value already matches).
* PeakMeter no longer compresses every transient on DSP-active
  slots - the limiter still protects against earrape but the main
  quality drop reported as "compressed YouTube" is gone.
* Robotic transient on toggling "Mute on my client" (or any
  capture / playback enable change) eliminated by giving each path
  its own EQ + Positional + Reverb state.
* Robotic burst on starting a new sound on a sandbox-active slot
  eliminated by resetting per-slot DSP state in playSoundInSlot.
* Robotic burst on activating 3D mode eliminated by snapping
  Positional smoothers to target on reset, resetting PathState on
  spatial-mode transitions, and guarding Reverb buffer realloc
  against same-rate setSampleRate calls.
