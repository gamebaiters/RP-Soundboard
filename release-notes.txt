GameBaiters Soundboard 1.0.114
==============================

Critical macOS fix
------------------
* Plugin failed to open on every Mac after install. Root cause: the
  install script and the auto-updater helper script only stripped
  com.apple.quarantine from a hardcoded list of dylib name patterns
  (libav*, libsw*, librp_soundboard_fx*). The 1.0.113 bundle ships
  another ~10 transitive dependencies (libssl, libcrypto, libvpx,
  libdav1d, libmp3lame, libopus, libSvtAv1Enc, libx264, libx265,
  libvmaf) which retained the quarantine xattr inherited from the
  download. macOS Gatekeeper then refused to dlopen them and
  TeamSpeak 3 reported "failed to open plugin".

  Fix: install_embedded_macos.sh and the auto-updater __APPLE__
  helper now run xattr -cr on the entire plugin folder after copy
  (clears quarantine + provenance + every other xattr). Each
  Mach-O is also re-signed ad-hoc on the user's machine so
  Gatekeeper has a fresh, locally-attached signature on every
  binary the plugin will dlopen.

Reminder for users on Apple Silicon
-----------------------------------
* TeamSpeak 3 on macOS is x86_64-only regardless of Mac hardware -
  it runs through Rosetta 2 on Apple Silicon. The plugin therefore
  ships as x86_64; that matches what TS3 expects when loading
  plugins under Rosetta.

Carried over from 1.0.113
-------------------------
* Recursive dependency bundler with @loader_path rewrites. Plugin
  dylib + every Homebrew transitive dep ship together; nothing
  references /usr/local or /opt/homebrew at runtime.
* Qt framework refs rewritten to @rpath/<framework>.framework/...
  so TS3.app's Qt frameworks resolve at load time.
* Strip ad-hoc signature before install_name_tool changes; final
  3-pass sweep catches any silent rewrite failures.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots)
* Update channel served from this gamebaiters branch on GitHub

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, RIGHT-CLICK
  Install Soundboard.app -> Open the first time so macOS Gatekeeper
  accepts the ad-hoc signature.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts (in the release assets) keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
