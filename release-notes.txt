GameBaiters Soundboard 1.0.18 - gamebaiters branch release
============================================================

This is the GameBaiters fork of MGraefe's RP-Soundboard. Compared to the
original plugin, this branch ships the following features (all on top of
upstream commit 64794fd, "Update to ffmpeg 8, build pipeline improvements"):

UI / playback effects
---------------------
* Pitch slider           - shift sample pitch independently of speed
                           (range 0.5x - 2.0x)
* Speed slider           - change playback rate without re-pitching
                           (range 0.5x - 2.0x)
* Pitch + Speed slider   - linked control that drives pitch and speed
                           together for the classic "chipmunk / slow-mo"
                           effect, with a Sync/Reset toggle
* Reverb slider          - real-time reverb intensity per playback
                           (range 1.0x - 20.0x)
* Earrape protection     - local hard-limiter that prevents accidental
                           ear-blasting peaks; only affects what YOU hear,
                           remote listeners hear the unaltered stream
* Remember pitch/speed/reverb - per-button toggle: when set, the slot
                           keeps the last pitch/speed/reverb you used
                           across restarts and config switches

Transport controls
------------------
* Skip +/- 5s            - jump 5 seconds forward or backward inside
                           the currently playing sample
* Skip +/- 10s           - same as above, larger increment
* Realtime waveform view - live waveform of the playing sample with
                           click-to-seek; drag to scrub the playhead
                           anywhere in the file

Multi-soundboard mode
---------------------
* Up to 5 soundboards can play simultaneously (slots 0-4)
* Independent buttons, hotkeys, volume, pitch, speed, reverb,
  earrape protection per slot
* Per-sound settings (loop, crop, custom FX, custom color, etc.)
  redesigned to address each slot independently

Plus the usual fork items
-------------------------
* Update channel migrated to GitHub
  (raw.githubusercontent.com/gamebaiters/RP-Soundboard/gamebaiters/version.xml)
* Dark-mode override removed - the plugin now follows TeamSpeak's
  current QPalette (light/dark/custom theme - all supported)
* Build pipeline supports static FFmpeg linking (FFMPEG_STATIC=ON),
  MSVC + MinGW + macOS targets
* Project target renamed to rp_soundboard_fx; output binary is
  rp_soundboard_fx_win64.dll

Installation
------------
Double-click rp_soundboard_fx_1.0.18.ts3_plugin and follow the
TeamSpeak installer prompts. To uninstall completely, use the
uninstall_soundboard.bat / .sh / _macos.sh scripts shipped alongside
the build (they wipe DLL, asset folder, logs and settings.db
plugin entries; a backup of the TS3 plugins folder is created on
the Desktop before any deletion happens).

Build from source
-----------------
git clone -b gamebaiters https://github.com/gamebaiters/RP-Soundboard.git
Requires Qt 5.15, Visual Studio 2017+ (Windows), CMake 3.12+, and
either system FFmpeg or a static build under ffmpeg/lib_*/.
