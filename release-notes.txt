GameBaiters Soundboard 1.0.112
==============================

Critical fixes
--------------
* Windows plugin now ships as a single self-contained DLL with FFmpeg
  statically linked in. The 1.0.111 attempt bundled six FFmpeg .dll
  files alongside the plugin, cluttering the user's plugins folder
  and leaving a fragile setup. CI now builds FFmpeg n6.1.1 from
  source with the MSVC toolchain (--toolchain=msvc, --enable-static
  --disable-shared) and links it directly into rp_soundboard_fx_win64.dll.
  Result: one binary, no runtime DLL dependencies.
* macOS install bundle Install_Soundboard_macOS.zip is now produced
  by CI and attached to every release. Earlier releases were missing
  it - macOS users had no double-click install path. The .app inside
  is ad-hoc-signed and contains the embedded .ts3_plugin plus the
  install script.

UI fixes (carried over from 1.0.110/111)
----------------------------------------
* Checkbox indicators no longer render the playback arrow icon when
  toggled - clean filled square in the accent color.
* Per-slot FX slider labels and value readouts at 9-10 pt regular
  weight; "Reset" button widened so the text never gets clipped.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection (local hard-limiter)
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots playing concurrently)
* Update channel served from this gamebaiters branch on GitHub
* Auto-updater that closes TeamSpeak, removes the previous binary,
  preserves your rp_soundboard.ini config, then runs the installer

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, double-click
  Install Soundboard.app. Right-click -> Open the first time if macOS
  Gatekeeper blocks it.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts (in the release assets) keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
