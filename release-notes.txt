GameBaiters Soundboard 1.0.113
==============================

Critical fixes
--------------
* macOS plugin failed to load on every Mac that didn't have Homebrew
  FFmpeg installed at the exact /usr/local/Cellar/ffmpeg/... path.
  The CI build baked Homebrew's absolute install_name into the
  plugin dylib's dependency list, so dyld couldn't find the FFmpeg
  libraries on user machines and TeamSpeak 3 marked the plugin as
  broken. Fixed: CI now rewrites every dep path to @loader_path so
  the bundled FFmpeg dylibs sitting next to the plugin resolve
  correctly. Inter-FFmpeg refs (libavformat -> libavcodec etc.)
  also rewritten. Every binary re-signed ad-hoc after the rewrite.
  A sanity check rejects the build if any /usr/local or /opt/homebrew
  path is left in any shipped binary.
* macOS uninstall script could not find the TS3 base directory.
  The candidate list missed the canonical macOS path
  ~/Library/Application Support/TeamSpeak 3 (with the space).
  Added it as the first candidate; TS3Client and ~/.ts3client kept
  as fallbacks for legacy installs.

Carried over from 1.0.112
-------------------------
* Windows plugin ships as a single self-contained DLL with FFmpeg
  statically linked in. No runtime FFmpeg DLL files alongside the
  plugin.
* macOS install bundle Install_Soundboard_macOS.zip is built and
  attached to every release.
* Checkbox indicators no longer render the playback arrow icon when
  toggled.
* Per-slot FX slider labels and value readouts at 9-10 pt regular
  weight; "Reset" button widened so the text never gets clipped.

Existing fork features
----------------------
* Pitch / Speed / Pitch+Speed / Reverb sliders
* Earrape protection (local hard-limiter)
* Remember pitch / speed / reverb per slot
* Skip +/- 5s and +/- 10s transport
* Real-time waveform with click-to-seek
* Multi-soundboard mode (up to 5 slots playing concurrently)
* Update channel served from this gamebaiters branch on GitHub
* Auto-updater that closes TeamSpeak, removes the previous binary,
  preserves your rp_soundboard.ini config, then runs the installer

Installation
------------

* Windows: download rp_soundboard_fx_<version>.ts3_plugin and
  double-click. TeamSpeak's bundled installer takes over.
* macOS: download Install_Soundboard_macOS.zip, unzip, double-click
  Install Soundboard.app. Right-click -> Open the first time if macOS
  Gatekeeper blocks it.
* Linux: from your TeamSpeak install directory run
    LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH ./package_inst <path-to-.ts3_plugin>

Uninstall scripts (in the release assets) keep your rp_soundboard.ini
config by default - press Y at the first prompt for a full wipe.
